# श्रमदान · Shramdaan

Unofficial fan-made, frontend-only Next.js 15 + TypeScript game (Nepali/English). No backend; progress is saved in localStorage.

## Run

npm install && npm run dev

## Deploy (Vercel)

Push to GitHub, import in Vercel, set NEXT_PUBLIC_SITE_URL to your final URL (used for canonical, sitemap, OG, JSON-LD).

## SEO included

Metadata API (title, description, keywords, OG, Twitter, canonical), JSON-LD (WebSite, VideoGame, FAQPage), sitemap.xml, robots.txt, web manifest, generated OG image, crawlable bilingual text, semantic HTML.
